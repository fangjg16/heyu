# Startup Design（网页章节方法）

网页生成不上网、不派生子代理。用下列问题组织已有资料。

## 行业与市场

- 市场怎么切；TAM/SAM/SOM 必须带来源和日期
- 谁痛、替代是什么、这类项目常见失败模式
- 单位经济锚（CAC/LTV/ churn / ACV）若无数据标假设

## 业务

- 问题、方案、不公平优势、关键指标（Lean Canvas）
- 已有交付才写短路径；没有交付不要编 Journey

## 验证

- 哪些假设必须先被客户行为证明
- 家办语境下「该停」= 不投或不追投的可测条件

# Startup Design（网页落盘）

按阶段把总文件写入项目资料包 `AI生成/startup/{folder}/`。同一路径再生成是新版本。知识网络章节由这些文件渲染，不要输出 HTML。

网页生成不上网检索、不 spawn 子代理。方法里的搜索步骤改为组织已有附件与用户访谈纪要中的事实。缺证据写「待补」，禁止编造。

创业财务不要 IRR / MOIC / 投资人 Down/Base/Up 三情景。市场规模写「总市场 / 可服务市场 / 可获得份额」，不要把 TAM/SAM/SOM 当主标题。

不要产出 `03-brand/` 任何文件。

## 产出顺序与文件

### 01-discovery/

- `market-analysis.md` — 市场是否存在：规模（带来源和日期）、切法、增速、成熟度、监管摘要、时机
- `competitor-landscape.md` — 如何竞争：对手档案、对比矩阵、定位图、弱点
- `industry-trends.md` — 时机是否合适：技术/监管/行为趋势与含义
- `target-audience.md` — 服务谁：画像、痛点层级、JTBD、购买与渠道
- `confidence-dashboard.md` — 哪些结论可靠、哪些仍是假设
- `research-gate.md` — 市场研究是否允许项目继续（继续 / 调整 / 停止）

### 02-strategy/

见 `references/output-specs.md` Phase 4：`lean-canvas.md`、`business-model.md`、`value-proposition.md`、`positioning.md`、`go-to-market.md`。

### 04-product/

见 output-specs Phase 6：`mvp-definition.md`、`user-journey.md`、`feature-prioritization.md`。没有真实交付时用户旅程标假设，不要编造已经上线的产品。

### 05-financial/

- `revenue-model.md` — 怎么赚钱（定价、收入线）
- `cost-structure.md` — 怎么花钱（跑道、消耗）
- `projections.md` — 三年收入/成本/现金流与敏感假设，禁止三情景 IRR

### 06-validation/

见 output-specs Phase 8：`risk-analysis.md`、`assumptions-tracker.md`、`validation-playbook.md`、`experiment-design.md`、`kill-criteria.md`。家办语境「该停」= 不投或不追投的可测条件。

### 00-overview/ 与 07-next/

- `scorecard.md` — 综合总评（明确建议）
- `README.md` — 执行摘要 / 项目简报
- `07-next/action-plan-30-days.md` — 未来 30 天行动

## 每个文件必须有的结构

见 `references/output-guidelines.md`：文首标题/阶段/日期/置信；文末 Flags（红旗/黄旗）与 Sources。主张必须标 [Data] / [Estimate] / [Assumption] / [Opinion]。

诚实协议见 `references/honesty-protocol.md`。框架定义见 `references/frameworks.md`。

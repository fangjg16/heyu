## 1. 证据优先级

按以下顺序解决冲突：

1. 已核验的收入、毛利、EBITDA、NOI、资产价值或交易范围构成。
2. 合同、订单或项目材料对实际产品、服务、客户、交付物、计价方式的描述。
3. 管理层或用户对主营业务和本次投资范围的明确说明。
4. 项目简介、官网宣传和项目名称中的具体业务词。
5. 根据关键词或一般行业常识作出的推断。

低优先级信息不得覆盖高优先级证据。项目名称只提供线索，不能单独证明业务实质；但即使只有名称，也必须按第 2 节返回一个低置信度分类。

## 2. 跨一级候选与强制裁决

### 2.1 先选二级候选

不得先锁定一级主题。先从完整白名单中提出 2–4 个最可能的二级标签，候选可以跨越多个一级主题。每个候选按以下五项比较：

1. **核心交付物**：客户实际购买的是资产使用权、实体产品、软件使用权、专业服务、作业结果、交易撮合还是金融责任。
2. **收入计价**：租金、商品差价、制造货款、订阅/许可费、项目费、管理费、佣金、广告费、运费、诊疗费或票房等。
3. **核心资产与能力**：物业、设备与产能、运营网络、牌照资质、供应链、软件/IP、内容版权、渠道关系或资金管理能力。
4. **价值链环节**：开发、制造、加工、持有、运营、运输、仓储、分销、零售、专业服务、技术供应或资管。
5. **客户场景**：仅用于区分专门垂直标签；客户所属行业本身不能替代前四项。

### 2.2 评分与平局顺序

需要强制裁决时，可按以下权重记录候选分数：

- 核心交付物匹配：0–4
- 收入计价匹配：0–3
- 核心资产与能力匹配：0–2
- 价值链环节匹配：0–2
- 客户场景匹配：0–1

得分最高者成为主分类。不得为了提高分数而补造输入中没有的事实。分数相同时依次使用：

1. 核心交付物有直接证据者；
2. 计价方式有直接证据者；
3. 更能描述标的自身、而不是客户行业或营销用途者；
4. 更专门且明确包含该业务的垂直标签；
5. 在 `taxonomy.md` 中位置更靠前的候选。

第 5 项只是保证系统始终产生唯一结果的最终平局规则。使用该项时，匹配类型必须为 `closest`，置信度必须为低。

### 2.3 无完全匹配或无资料

- 没有完全对应标签：选择得分最高的正式标签，使用 `closest`，不得自创标签。
- 只有名称：使用名称中最具体的产品、资产或行业词生成候选，选择 `closest`，置信度为低。
- 完全没有产品、服务、行业、客户、资产或业务词，或所有具体标签在核心交付物和价值链环节两项均为 0 分：固定使用 `现代服务业 → 综合商业运营与其他企业服务`，匹配类型为 `closest`，置信度为低。
- 无论何种情况，`primary.theme` 与 `primary.subsector` 均不得为空。

## 3. 经济重心与主次分类

### 3.1 主导指标

先判断本次实际投资范围，再根据业务模式选择主导指标：

- 资产持有型：优先 NOI、资产价值和租赁现金流。
- 制造及运营服务型：优先 EBITDA 或毛利，其次收入。
- 分销贸易型：优先毛利和承担库存/信用风险的收入，不以流水或采购额代替。
- 平台撮合型：优先净收入、佣金或广告毛利，不以 GMV 直接代表经济重心。
- 金融及资管型：优先管理费、利差/保费收入、管理资产对应收益和实际承担的金融责任。
- 尚未形成稳定收入：优先本次交易对价或投入资本所对应的资产、已签合同交付物和明确的首要商业化产品。

不同指标指向不同业务时，使用与该商业模式最匹配的指标，不把收入、资产价值和“投资命题”任意并列。量化数据仍无法区分时，依次看本次投资范围、独立合同数量、核心管理团队与主要投入资源，最后执行第 2.2 节平局规则。

### 3.2 次分类门槛

默认只给一个主分类。业务线同时满足以下条件时才可列为次分类：

- 有独立交付物或资产；
- 有独立客户合同或可分辨的收入/资产；
- 对收入、EBITDA、资产价值或本次交易对价具有实质影响。

有可靠量化数据时，单项达到相关主导指标约 20% 可视为实质影响；低于 20% 但属于本次明确单独承保的资产或业务，也可以列为次分类。功能、客户行业或营销词不构成次分类。最多两个次分类。

## 4. 通用边界规则

- **行业不等于客户行业**：向医院出售通用招聘服务，归“人力资源与外包”，不归医疗健康。
- **工具不等于被服务业务**：为物流企业销售路线优化 SaaS，归软件；不因客户是物流企业而归物流。
- **交易形式不等于行业**：roll-up、控股收购、少数股权、REITs 申报、SPV 或基金结构不决定主题。
- **制造与分销分开**：自有工艺、产线和质量责任是核心时归制造；取得商品所有权并依靠进销差价变现时归分销。
- **分销、供应链服务与平台分开**：承担库存或信用风险并赚取差价是分销；代表客户执行采购、结算并收服务费是供应链管理；连接买卖双方并收佣金或广告费是互联网平台。
- **专门分销优先**：医药、医疗耗材、农资、化工品、建材、汽车和工业/电子元器件已有专门标签时，优先专门标签；只有跨品类采购执行、结算和配套服务才使用一般供应链管理与贸易服务。
- **资产持有与作业运营分开**：通过物业租金和资产升值变现，优先地产；通过运输、仓储、配送、设施或设备服务费变现，优先对应运营赛道。
- **品牌与加工分开**：面向消费者经营品牌和渠道，优先品牌消费；以工厂加工、B2B 供货和食品供应链为核心，优先食品加工与供应链。
- **设备销售与服务分开**：收入主要来自设备货款且承担制造质量责任，归设备制造；收入主要来自可用率、维保工时、备件或节能结果，归对应运维服务。
- **垂直运营与集团整合分开**：经营单一医院或专科连锁，使用医院/专科标签；只有持续收购多家机构、存在集团级整合团队和共享运营体系时，才使用民营医疗集团化并购与区域整合。

## 5. 高频相邻赛道边界

### 地产、仓储、园区与设施

- 开发、持有并出租仓库、冷库、园区或数据中心载体：`地产与建筑/资管 → 工业/物流地产`。
- 为货主提供入库、存储、拣选、配送等第三方作业：`物流与供应链 → 仓配一体化与第三方仓储`。
- 围绕农产品或食品提供产地冷链设施、食安检测或追溯：`农业与食品 → 冷链基础设施与食安检测/追溯`。单纯持有冷库收租仍归工业/物流地产。
- 以 REITs 发行准备、多个底层资产的组合培育和持续资产运营为核心：`地产与建筑/资管 → REITs 标的培育与资产运营`。仅持有一个可申报 REITs 的物业不自动使用该标签。
- 服务住宅或商业物业业主，收入来自物业费、保洁安保和社区增值：`地产与建筑/资管 → 物业管理与增值服务`。
- 面向企业客户承包办公楼、医院或园区的综合后勤、保洁安保和设施管理：`现代服务业 → 物业后勤/园区运营/综合设施管理`。
- 围绕工业生产设备提供可用率保障、维保、OEM 备件或生产辅助：`工业与制造 → 工业设备运维、OEM备件与园区生产服务`。
- 线下房地产居间、代理销售、租赁撮合或门店经纪：`地产与建筑/资管 → 房地产经纪、交易与租赁服务`；经营多边线上房产信息平台并收会员或广告费，归互联网与数字平台。

### 消费、餐饮与食品

- 消费品品牌公司：`消费与零售 → 品牌消费`。
- 门店网络和标准化复制是核心，尤其茶饮、咖啡、烘焙、餐饮、医美或健身连锁：`消费与零售 → 专业连锁`。
- 单体或区域性餐饮、美业、健身等现场消费服务，没有形成可复制连锁网络时：`现代服务业 → 宠物服务、生活服务与本地服务运营`。
- 主要向渠道或餐饮客户进行食品生产加工和供应：`农业与食品 → 食品加工与供应链`。
- 回收、翻新和转售消费品：`消费与零售 → 二手与循环经济`；处理工业固废、危废或再生资源的处置运营则归环保与公用事业。

### 营销、内容、演出与文旅

- 以会展、品牌活动落地、拍摄制作或客户委托内容交付收项目费，且不以媒体预算代理或版权经营为核心：`现代服务业 → 会展/活动执行与受托内容制作`。
- 以广告策略、公关、媒体预算和整合传播代理为主营：`文化与传媒 → 广告代理/整合营销/公关公司`。
- 以营销软件、数字广告交易、流量分发或交易抽成变现：`互联网与数字平台 → 数字广告、营销科技与流量商业化平台`。
- 持有或承担版权内容投资风险，并通过出版、发行、院线或版权销售变现：`文化与传媒 → 出版/院线/发行与版权内容制作公司`。
- 以达人或艺人经纪佣金、MCN 分成、演出内容组织费变现：`文化与传媒 → MCN/艺人经纪与演出内容组织`。
- 以场馆、赛事或现场演出的票务、赞助、场租和现场消费变现：`文旅与休闲 → 演出赛事与体育娱乐、文体场馆运营`。
- 直播或短视频仅是自有品牌的销售渠道，仍按消费品分类；经营多边直播/内容交易平台并收佣金或广告费，使用直播电商平台标签。

### 金融、资管与数据服务

- 只有实际承担资金、信用、承销、保险、管理或结算责任时，才归金融与资管。企业仅因融资、接受投资、设置基金或 SPV，不归金融。
- 资产运营平台以受托管理费、基金管理费或资产组合运营收益为核心，使用`金融与资管 → 资管与资产运营平台`；单体资产经营仍按资产本身分类。
- 面向多行业出售人工研究、企业名录、商业情报或项目制数据服务：`现代服务业 → 商业信息、数据与专业研究服务`。
- 以编辑内容、订阅、发行或广告为主的财经新闻媒体：`文化与传媒 → 新闻、财经信息与专业媒体`。
- 面向金融投资工作流销售标准化数据终端、API、另类数据或投研软件：使用金融科技对应标签。
- 数据库、数据治理或 BI 产品归软件与企业服务；数据交易所、数据经纪和多边数据流通平台归互联网与数字平台。

### 医疗、养老与专业连锁

- 医美门店连锁可落在消费与零售的专业连锁；以医疗资质、诊疗服务和临床能力为核心的专科机构优先医疗健康。
- 医美产品按注册与产品实质分类：药品或生物制品归`医美生物制品与药品`；注册医疗器械归`医美器械与注射填充产品`；仅生产上游材料则归新材料。
- 养老、护理和康复机构归医疗健康；普通长租公寓或适老住宅资产运营仍归地产。
- 药店、DTP 和面向患者的医药零售归`体检与健康管理、医药零售与DTP`；面向医院、药店和经销商的药品批发及配送归`医药商业、药品批发与专业配送`；耗材 SPD 和院内耗材供应链归医疗耗材流通标签。
- 临床检验、病理或影像诊断服务归医疗健康；制造 IVD 产品归医疗器械；跨行业通用实验室检测归现代服务业。

### 能源、矿业、工业与环保

- 煤炭开采、洗选以及以煤炭为核心的物流港储：`能源与资源 → 煤炭开采与洗选、煤炭物流与散货港储`。
- 铜、铝、锂、镍、稀土等金属矿的开采与选冶：使用对应金属矿产资源标签，不归煤炭标签。
- 炼油、乙烯等基础石化和大宗基础化学品生产：`能源与资源 → 炼油、基础石化与大宗基础化工制造`；精细化工、专用化学品和中间体归新材料与先进化工；只做化工品贸易归化工品贸易与分销。
- 水泥、普通玻璃、砖瓦和非金属矿物制品生产归传统建材制造；高性能玻璃、特种陶瓷或功能材料归新材料。
- 通过 EMC、节能收益分成或大气治理项目变现：`环保与公用事业 → 大气治理与节能改造`。
- 工业设备检修、技术改造和节能服务费：`工业与制造 → 第三方检修/改造/节能服务`。
- 新能源电站或储能资产的独立运维、检测和技术服务：`新能源与清洁技术 → 新能源资产运维与技术服务`；拥有电站并销售电力则归发电运营。
- 环境治理项目配套的污染物监测、环境质量或修复验收，归环境检测；跨行业通用检测、认证、计量与实验室服务归现代服务业；检测仪器制造归先进制造。

### 交通、汽车与基础设施

- 网约车、公交、城际客运和共享出行：`交通出行与汽车服务 → 客运与出行服务`。
- 民航客运、机场航站楼和综合客运枢纽运营：`交通出行与汽车服务 → 民航客运、机场与综合交通枢纽运营`；航空货运归物流；飞机制造归航空航天。
- 新车经销、4S 店集团和汽车品牌渠道服务：`交通出行与汽车服务 → 新车经销与汽车渠道服务`；维修保养、二手车和汽车美容归车后市场。
- 轨道交通车辆、信号和智能交通装备统一归`汽车与智能交通 → 轨道交通车辆、信号与智能交通装备`；工业与制造的重型装备标签不再包含轨道交通。

## 6. 技术与新经济边界

- **软件与行业业务分开**：靠软件订阅、许可或技术服务变现，归软件或对应垂直科技类；不因客户是物流、地产或能源企业而归客户行业。
- **SaaS 与互联网平台分开**：向单一组织提供工具并按席位、模块或用量收费，优先软件；连接多边用户并通过佣金、广告、流量或交易抽成变现，优先互联网平台。
- **纯软件口径**：有可靠数据时，许可、订阅或用量型技术收入达到 50% 通常视为纯软件；即使未达 50%，若核心交付物是可复制软件/IP，客户为使用权与功能付费，仍按软件或垂直科技分类。客户主要为作业结果、交易执行或实体结果付费，核心资产是人员、运营网络、资质、供应链或设施时，归对应运营标签。
- **AI 按产品层归类**：基础模型与通用 AI 应用归软件；AI 芯片归半导体；AI 算力服务归云与数据基础设施；金融、医疗等已有垂直标签的 AI 产品优先垂直类。
- **持牌金融与金融科技分开**：承担资金、信用、承销、管理或结算责任，按金融与资管分类；向金融机构或投资者销售软件、数据或技术服务，按金融科技分类。
- **医疗服务与数字医疗分开**：实际提供诊疗、检验、康复或健康管理，归医疗健康；销售医疗软件、器械或临床决策工具，归医疗器械与数字医疗。
- **数据中心资产与技术运营分开**：开发、持有并出租物理载体，归工业/物流地产；销售机柜、算力、云、CDN 或托管运维服务，归云计算、数据基础设施与网络安全。
- **卫星按交付物分类**：通信连接、卫星互联网带宽或导航定位服务归通信与物联网；卫星/载荷制造、发射、遥感影像、测绘或空间数据产品归航空航天。
- **智能交通/V2X 按运营层级分类**：经营运力、出行或停车服务归交通运营；路车协同系统、智能交通集成、车载/路侧设备归汽车与智能交通；C-V2X 模组、通信专网、基站或连接服务归通信与物联网。
- **无人机按应用场景分类**：个人航拍和娱乐整机归智能硬件；工业巡检、测绘、农业、物流、应急无人机及 eVTOL 归第 28 类；芯片、模组、传感器或材料按零部件实质分类。
- **机器人按应用场景分类**：手术、医疗和康复机器人归医疗器械；家庭与消费级机器人归智能硬件；工业、物流、建筑、农业、商用服务与特种机器人归先进制造；只销售通用机器人软件则归软件。
- **动力电池链条分开**：独立电芯、储能电池与非车用电池制造归新能源；车用 Pack、BMS、电机、电控与热管理归汽车与智能交通；正负极、电解液、隔膜等归新材料；回收与再制造运营归环保。
- **新能源资产、设备、运维与材料分开**：电站投资运营、设备制造、第三方资产运维和关键材料分别使用对应标签，以本次投资范围内的交付、收入和核心能力裁决。
- **传统制造与先进制造分开**：标准化通用装备、传统工艺和成本/规模驱动的零部件归工业与制造；高精度、高技术壁垒、自动化控制或先进核心工艺是主要竞争力时归先进制造。不得仅因宣传中出现“高端”“智能”就归先进制造。
- **半导体材料与电子材料分开**：直接用于晶圆制造、封装测试且具有半导体专用规格的材料归半导体；显示、光学、陶瓷及一般电子功能材料归新材料。
- **光通信与光电器件分开**：光模块、光纤光缆和传输设备归通信与物联网；上游激光器、探测器和通用光电器件归半导体与电子元器件。
- **物联网、智能硬件与企业计算设备分开**：连接模组、通信平台和行业连接方案归通信与物联网；面向消费者的智能终端归智能硬件；服务器、存储和企业级计算硬件制造使用专门企业硬件标签。
- **军工按产品实质分类**：军用芯片归半导体；军用通信归通信与物联网；军用车辆归汽车与智能交通；舰船与通用重型装备归工业与制造；军机、航天装备及无更精确标签的特种装备归第 28 类。
- **前沿交叉不是一般兜底**：只有量子、脑机接口、核聚变等有明确技术路线和商业模式、且无更精确标签的前沿技术才使用该类。没有业务线索时使用综合商业运营兜底标签。

## 7. 标签说明与范围限定

`taxonomy.md` 只保存正式标签。下列说明用于约束容易误用或本次新增的标签：

| 正式标签 | 说明 | 性质 |
|---|---|---|
| 工业/物流地产 | 园区、仓库、冷库、数据中心物理载体的开发持有和租赁 | 范围限定 |
| 房地产经纪、交易与租赁服务 | 线下居间、代理销售、租赁撮合；不含多边线上信息平台 | 范围限定 |
| 会展/活动执行与受托内容制作 | 客户委托的活动或内容项目，不以媒体预算代理和版权经营为核心 | 范围限定 |
| 综合商业运营与其他企业服务 | 仅在完全没有可用业务线索，或其他正式标签均无合理接近关系时兜底 | 范围限定 |
| 民航客运、机场与综合交通枢纽运营 | 不含航空货运、飞机制造和纯观光交通 | 范围限定 |
| 工业品、电子元器件与专业分销 | 取得商品所有权、承担库存或信用风险并赚取差价 | 范围限定 |
| 工业设备运维、OEM备件与园区生产服务 | 围绕生产设备可用率、维保和备件交付；不含物业后勤 | 范围限定 |
| 建材、玻璃、水泥与非金属矿物制品制造 | 普通建材制造；高性能功能材料归新材料 | 范围限定 |
| 医药商业、药品批发与专业配送 | 面向医疗机构、药店或经销商的药品 B2B 流通 | 范围限定 |
| 炼油、基础石化与大宗基础化工制造 | 不含精细化工、专用化学品及单纯贸易 | 范围限定 |
| 出版/院线/发行与版权内容制作公司 | 持有或承担内容版权投资风险 | 范围限定 |
| MCN/艺人经纪与演出内容组织 | 经纪佣金、内容分成和演出组织；不含场馆经营 | 范围限定 |
| 新能源资产运维与技术服务 | 第三方电站、储能等资产运维；资产所有者售电归发电运营 | 范围限定 |
| 服务器、存储与企业级计算硬件制造 | 企业级计算硬件，不含云和算力服务 | 范围限定 |

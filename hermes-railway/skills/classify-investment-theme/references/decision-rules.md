## 1. 证据优先级

按以下顺序解决冲突：

1. 已核验的收入、毛利、EBITDA、资产价值或交易范围构成。
2. 项目材料对实际产品、服务、客户、合同和收费方式的描述。
3. 管理层或用户对主营业务和投资命题的明确说明。
4. 项目简介、官网宣传和项目名称。
5. 根据关键词或常识作出的推断。

低优先级信息不得覆盖高优先级证据。项目名称只提供线索，不能单独证明业务实质。

## 2. 经济重心判断

依次判断：

- 钱从哪里来：谁付费，为何付费，主要收入或利润来自什么。
- 资本沉淀在哪里：核心价值是持有资产、运营网络、专业服务、渠道关系还是生产能力。
- 标的实际做哪一环：开发、制造、加工、持有、运营、运输、仓储、分销、零售、专业服务或资管。
- 本次买什么：单体业务、资产包、运营平台、集团公司还是技术供应商。

有量化构成时，以本次投资范围内最能代表持续收入、利润或资产价值的业务作为主分类。没有量化构成时，以商业模式和投资命题共同判断，匹配类型为 `closest` 并降低置信度。

## 3. 通用边界规则

- **行业不等于客户行业**：向医院出售通用招聘服务，归“人力资源与外包”，不归医疗健康。
- **工具不等于被服务业务**：为物流企业销售纯 SaaS，不能仅因客户是物流企业而归物流与供应链。
- **交易形式不等于行业**：roll-up、控股收购、少数股权、REITs 申报、SPV 或基金结构不决定主题。
- **专门分销优先于一般贸易**：医疗耗材、农资、化工品、建材、汽车配件已有专门标签时，优先使用专门标签；只有跨品类采购执行、结算和配套服务才使用一般贸易、进出口与供应链服务。
- **资产持有与作业运营分开**：通过物业租金和资产升值变现，优先地产/资管；通过运输、仓储、配送、设施服务费变现，优先对应运营赛道。
- **品牌与加工分开**：面向消费者经营品牌和渠道，优先品牌消费；以工厂加工、B2B 供货和食品供应链为核心，优先食品加工与供应链。
- **垂直运营与集团整合分开**：经营单一医院或专科连锁，使用医院/专科标签；投资命题本身是跨机构收购整合平台时，才使用民营医疗集团化并购与区域整合。

## 4. 高频相邻赛道边界

### 地产、仓储与物流

- 开发、持有并出租仓库、冷库、园区或数据中心载体：`地产与建筑/资管 → 工业/物流地产`。
- 为货主提供入库、存储、拣选、配送等第三方作业：`物流与供应链 → 仓配一体化与第三方仓储`。
- 围绕农产品或食品提供产地冷链基础设施、食安检测或追溯：`农业与食品 → 冷链基础设施与食安检测/追溯`。
- 以 REITs 发行准备、底层资产组合培育和持续资产运营为核心：`地产与建筑/资管 → REITs 标的培育与资产运营`。仅持有一个可申报 REITs 的仓库不自动使用该标签。

### 物业、园区与设施服务

- 服务住宅或商业物业业主，收入来自物业费、保洁安保和社区增值：`地产与建筑/资管 → 物业管理与增值服务`。
- 面向企业客户承包办公楼、医院、园区等综合后勤和设施管理：`现代服务业 → 物业后勤/园区运营/综合设施管理`。
- 围绕工业设备提供维保、OEM 备件和设备运维：`工业与制造 → 工业设备运维、OEM备件与园区生产服务`。

### 消费、餐饮与食品

- 消费品品牌公司：`品牌消费`。
- 门店网络是核心，尤其茶饮、咖啡、烘焙、餐饮、医美或健身连锁：`专业连锁`。
- 主要向渠道或餐饮客户进行食品生产加工和供应：`食品加工与供应链`。
- 回收、翻新和转售消费品：`二手与循环经济`；处理工业固废、危废或再生资源的处置运营则归环保与公用事业。

### 营销、内容与文旅

- 以品牌营销活动执行、会展或通用内容制作服务收费：`现代服务业 → 会展/活动执行与受托内容制作`。
- 以广告、公关、媒体预算和整合传播代理为主营：`文化与传媒 → 广告代理/整合营销/公关公司`。
- 以版权内容、出版、影视院线发行、艺人/创作者经纪或 IP 商业化为核心：使用文化与传媒对应标签。
- 以景区、目的地、场馆、赛事或酒店现场运营为核心：使用文旅与休闲对应标签。
- 线下演出场馆或赛事运营偏文旅与休闲；艺人经纪、MCN 和演出内容组织偏文化与传媒。根据收入合同和核心资源判断。

### 金融、资管与产业运营

- 只有实际提供信贷、担保、保理、融资租赁、财富管理、FA、支付收单或资产管理时，才归金融与资管。
- 企业仅因融资、接受投资、使用联合贷技术、设置基金或 SPV，不归金融与资管。
- 资产运营平台以受托管理费、基金管理费或资产组合运营收益为核心，使用`资管与资产运营平台`；单体资产经营仍按资产本身分类。
- `财富管理/FA/并购整合平台`中的并购整合平台指以发现、组织和完成并购整合为核心商业模式的平台，不等于所有 Buy-to-Build 或 roll-up 项目。

### 医疗、养老与专业连锁

- 医美门店连锁可落在消费与零售的专业连锁；以医疗资质、诊疗服务和临床能力为核心的专科机构优先医疗健康。说明判断依据。
- 养老、护理和康复机构归医疗健康；普通长租公寓或适老住宅资产运营仍归地产与建筑/资管。
- 医药零售与 DTP 归医疗健康；一般消费健康品牌不因宣传健康功效自动归医疗健康。

### 节能与工业服务

- 通过 EMC/合同能源管理、节能收益分成或大气治理项目变现：`环保与公用事业 → 大气治理与节能改造`。
- 以工业设备检修、技术改造和节能服务费变现：`工业与制造 → 第三方检修/改造/节能服务`。
- 传统电厂、区域热力和售电公司归能源与资源；为其提供设备或运维服务按实际设备/服务分类。

## 5. 名称不足与最近匹配

仅有项目名称时：

- 提取名称中可验证的业务词，但不要把品牌词、地点词或“科技”“产业”“资本”等泛词当作证据。
- 仍须返回最接近的白名单标签，置信度为低，并列出最可能改变分类的问题。
- 名称无法揭示业务、或所有具体标签在核心交付物和价值链环节上均为零匹配时，使用 `现代服务业 → 综合商业运营与其他企业服务`，匹配类型为 `closest`、置信度为低。

如果业务实质明确，但没有完全对应标签：

- 仍必须按交付物、计价方式、核心资产和价值链环节选择最接近的正式标签，匹配类型为 `closest`。
- 不得输出“暂定”“暂无法归类”“分类体系未覆盖”，不得将主分类字段留空。
- 不得把建议扩表标签写入正式字段。

## 6. 典型示例

| 项目描述 | 主分类 | 关键理由 |
|---|---|---|
| 自持冷库，主要向租户收租 | 地产与建筑/资管 → 工业/物流地产 | 收益核心是资产租赁 |
| 租用仓库为电商提供入库、拣选和配送 | 物流与供应链 → 仓配一体化与第三方仓储 | 收益核心是仓配作业 |
| 连锁咖啡门店 | 消费与零售 → 专业连锁 | 门店网络与现场服务是核心 |
| 为连锁餐厅生产预制菜 | 农业与食品 → 食品加工与供应链 | B2B 食品加工供货 |
| 为医院提供保洁、餐饮和设施维护外包 | 现代服务业 → 物业后勤/园区运营/综合设施管理 | 医院是客户，不是标的业务 |
| 收购区域眼科医院并持续经营 | 医疗健康 → 医院与专科连锁、康复/护理/养老 | 收购形式不改变医疗经营实质 |
| 以连续收购整合多家民营医院为核心投资命题 | 医疗健康 → 民营医疗集团化并购与区域整合 | 整合平台本身是业务命题 |
| 为物流公司销售通用路线优化 SaaS | 软件与企业服务 → 垂直行业软件/SaaS | 技术工具按其自身产品分类，不等于物流运营 |
| 管理多个仓储基金并收取管理费 | 金融与资管 → 资管与资产运营平台 | 收益来自受托资管和组合运营 |
| 运营单个产业园并向租户收取租金和物业费 | 地产与建筑/资管 → 工业/物流地产 | 单体资产租赁运营是经济重心 |

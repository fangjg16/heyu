# Deep Reference - Returns Analysis

Use by default for initial/full KB generation. Use whenever writing valuation-returns, decision-framework, or maturity scorecard for projects with proposed capital, pricing, revenue share, exit, repayment, or investor economics.

## Investor Economics First
Separate target operating economics from investor cash flow. Explain how the investor makes money: entry amount/price, instrument, ownership or claim, fees, repayment/distribution waterfall, duration, exit/refinancing, downside protection, and residual value.

## Scenario Standard
When numbers allow, show base/upside/downside with key drivers. When numbers do not allow, state what input blocks reliable modeling and use qualitative sensitivity.

## Required Sensitivities
Price/entry valuation, volume, conversion, utilization, margin, timing, capex/use of proceeds, regulatory approval, exit multiple, repayment/default, and FX/commodity/market variables where relevant.

## Routing
- Business revenue/cost assumptions -> business-operations.
- Investor IRR/MOIC/cash flow/exit -> valuation-returns.
- Missing model inputs -> diligence-gaps.
- Downside drivers -> risks-mitigation.
- Investment recommendation impact -> decision-framework.

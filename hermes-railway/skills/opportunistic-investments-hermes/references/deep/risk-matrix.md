# Deep Reference - Risk Matrix

Use by default for initial/full KB generation. Use whenever producing or refreshing risks-mitigation, decision-framework, or IC-facing output.

## Risk Row Standard
Each material risk should include: severity, category, concrete failure mode, cause, evidence basis, likelihood/impact if known, current mitigation, mitigation gap, owner/controller, trigger, affected value driver, and next action.

## Categories
Legal/ownership, regulatory/compliance, commercial, operational, financial/returns, counterparty, market, data/technology, execution/timing, reputational, and exit/liquidity.

## Red Flags
Separate stop/pause conditions from ordinary risks. A red flag should explain what evidence would clear it or why it blocks investment.

## Linkage
Risks must link to diligence-gaps when evidence is missing, valuation-returns when downside changes returns, and decision-framework when risk affects go/no-go.

## Anti-Pattern
Do not write generic labels such as "market risk" or "regulatory risk" without mechanism, consequence, and mitigation.

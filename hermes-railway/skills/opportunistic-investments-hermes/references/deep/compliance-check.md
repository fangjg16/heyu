# Deep Reference - Compliance Check

Use by default for initial/full KB generation. Use whenever the project touches regulated activity, licenses, approvals, privacy/data, cross-border matters, platform rules, advertising/content rules, financial promotion, healthcare, energy, commodities, IP, or public-market constraints.

## Analysis Frame
1. Who does what, where, for whom, using which asset/data/right/channel?
2. Which regulator, law, permit, approval, filing, platform policy, or industry rule applies?
3. Is it a gating issue, operating obligation, disclosure item, or monitoring item?
4. What is known, what is inferred, and what requires counsel/project-party confirmation?

## Routing
- Licenses, approvals, filings, privacy/data, platform obligations -> regulatory-compliance.
- Ownership/title/authorization -> legal-ownership.
- Penalty, shutdown, unenforceability, or blocked commercialization -> risks-mitigation.
- Counsel opinions, regulator confirmation, missing permits -> diligence-gaps.

## Guardrails
Do not present legal advice as final. Cite primary sources when available. If status is unknown, show the authority/source needed and investment implication.

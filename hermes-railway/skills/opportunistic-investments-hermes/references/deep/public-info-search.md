# Deep Reference - Public Information Search

Use by default for initial/full KB generation when project-specific uploads are thin or absent. Use for public research, regulatory checks, comparables, market context, and source index enrichment.

## Source Hierarchy
Prefer primary sources: regulators, courts, registries, exchange filings, company disclosures, official platform policies, signed/public transaction documents. Use media/industry articles as context, not final proof.

## Routing
- Project/counterparty/asset facts -> relevant project slots.
- Market size, demand, policy background -> industry-market.
- Comparable companies/transactions/platforms -> comps-benchmark.
- Regulatory sources -> regulatory-compliance.
- Dated industry history -> industry-market, not timeline.
- Pure source coverage windows -> Appendix A, not timeline.

## Evidence Discipline
For each finding, record date, source type, jurisdiction, certainty, and why it matters to this project. Repeated reposts do not count as independent sources.

## Public-Only KB
If no project uploads exist, be explicit: this is a public-information preliminary KB. Use missing callouts for project-specific slots rather than filling them with industry assumptions.

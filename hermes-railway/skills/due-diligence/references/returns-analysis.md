# Returns Analysis

Use in Phase 6. Translate diligence-adjusted (or, if those inputs do not yet exist, explicitly `indicative`) operating facts into investor cash flows, value, and price. The IC-facing presentation is domain 6 (`investment-structure-returns`) of `05-decision/investment-analysis-report.md`, written in Phase 8.

Underwriting is not diligence: it consumes verified facts and produces value and price, so it adds no new claim status. This is Phase 6 of `due-diligence` — not a separate skill, and not a deeper financial-diligence chapter. Historical order-to-cash, earnings quality, and accounting validation stay in financial diligence.

## How to underwrite

Build investor cash flows from explicit price, cheque size, ownership, dilution, debt, distributions, fees, taxes, follow-on, exit timing/value, and waterfall assumptions. If inputs are unknown, solve for ranges or maximum acceptable price instead of inventing a single case. Label the output `indicative` until material financial-diligence inputs have been checked; then `diligence-adjusted`.

Report IRR, MOIC, payback, break-even conditions, and cash-flow timing for base, upside, and downside. Sensitize only decision-relevant variables and show correlated cases where single-variable tables mislead. State input provenance, evidence status, formulas, and reconciliation to financial diligence.

Industry diligence owns operating comparables. This phase owns public valuation comparables, precedent transaction comparables, adjustments, implied value, and price consequences.

When cash-flow tables are too large for the report, write the working model to `04-underwriting/valuation-and-returns.md` and add `sensitivity-and-scenarios.md` if the sensitivities must stand alone. Domain 6 must still carry the decision-useful conclusion, scenarios, IRR/MOIC or “not measurable”, and maximum acceptable price. Do not leave domain 6 as a stub that only points at the model file.

Phase 8 presents this analysis in domain 6 of `dd-synthesis.md`. Keep one authoritative statement; do not write a second returns chapter elsewhere in the report.

# 正式行业尽调

Use in Phase 3D. Produce or update `03-diligence/industry-diligence.md` using every required formal section. Own the industry conclusion. When evidence is insufficient, mark the section `未核验`, state the investment consequence, and search in the same run using `references/shared/source-grading.md`. Keep valuation multiples in Phase 6 / report domain 6; use operating comparables here.

## 1. 目标与研究边界

公开研究是取证方法，行业尽调是把外部证据转成对标的可投资性判断。它必须回答：标的到底位于哪个行业坐标；需求为何产生；市场多大、增长从何而来；价值链和竞争结构如何；技术、监管和替代如何变化；这些事实是否支持标的收入、份额、定价、毛利和退出叙事。

正式行业尽调不得等同于“市场规模 + 几个竞品”。比例原则改变篇幅和抽样深度，不改变重大问题的可见性。

## 2. 行业定义与坐标

- 从标的实际销售对象、产品功能、产品形态、应用场景、客户行业、交易方式和收入来源反推行业。
- 建立“一级主题—二级赛道—具体可投子赛道—邻近市场—替代市场”的坐标，避免把内容 GMV、终端产值、平台交易额和软件支出相加。
- 说明供给侧与需求侧边界、地域、客户类型、产品范围、期间、币种、含税/不含税和是否含内部交易。
- 若公司横跨多个行业，分别计算与分析，不用宽口径大市场掩盖当期主营业务。

行业定义必须与业务尽调的一句话业务定义、合同标的和财务收入分类一致。

## 3. 行业逻辑与需求形成

解释产业存在的根本原因：谁有什么任务或约束、为何愿意付费、预算来自哪里、采购如何发生、现有方案为何不足。区分使用者、决策者、付款者、监管者和受益者。

分析需求频率、刚性、季节性、周期性、替代方案、转换成本、采用门槛、决策周期、验证标准和失败成本。把“有痛点”与“有预算、能采购、会复购”分开验证。

## 4. 发展历程与关键拐点

以时间轴解释行业起源、技术代际、供需变化、重大政策、渠道迁移、商业模式变化、资本周期和代表性公司兴衰。每个阶段说明竞争基础和利润池如何改变。

历史不是背景装饰；用于判断当前趋势是结构性、周期性还是短期事件，并识别标的是否重复已失败路径。

## 5. 市场现状、规模与增长

### 5.1 市场现状

说明当前供给数量、有效产能、需求数量、客户集中、价格带、产能利用、渗透、区域差异、交易量和产业集中度。区分名义参与者与实际活跃买方/卖方。

### 5.2 市场规模

同时使用至少两条独立路径，能取得数据时优先三角验证：

- 自上而下：权威统计或专业报告 × 明确可服务比例；
- 自下而上：可购买主体数 × 采用率 × 年频次 × 客单价；
- 供给交叉验证：有效供给/产能 × 利用率 × 单价；
- 公司反推：参与者收入、份额或客户队列汇总。

每个结果必须列公式、参数、来源 ID、期间、地域、口径、是否含税、置信区间和敏感性。解释各路径差异，禁止把内容交易总额直接当作工具或服务软件 TAM。

分别给出 TAM、SAM、SOM，并把 SOM 绑定到真实渠道、销售能力、产能、资金和时间。范围不确定时输出区间和概率，不输出伪精确单点。

### 5.3 增长与渗透

拆解历史增长率、价格/数量/结构贡献、渗透率、替代率和客户队列。比较标的预测增长与行业增长，识别预测要求的份额提升。核对不同来源定义和基期，避免直接拼接 CAGR。

## 6. 驱动因素与约束

从需求、供给、成本、技术、政策、资本、渠道和社会行为拆解增长驱动。每项驱动都要有传导链：变化变量 → 客户行为/供给能力 → 价格/数量/毛利 → 标的财务结果。

同样分析约束：预算、采购、人才、产能、数据、知识产权、合规、基础设施、替代品、信任和转换成本。将驱动和约束转成可监测指标及失效触发条件。

## 7. 价值链与利润池

- 绘制上游输入、中游产品/服务、渠道/平台、下游客户和终端受益者；
- 标明交易关系、价格形成、结算方式、账期、数据/知识产权流和监管责任；
- 估计各环节收入、毛利、资本强度、集中度和议价权；
- 识别瓶颈资源、价值迁移、纵向整合、平台抽成和替代风险；
- 将标的定位到具体环节，检验其议价、毛利和现金周期叙事。

## 8. 竞争结构与参与者

### 8.1 结构

判断行业集中度、进入/退出壁垒、规模效应、网络效应、品牌、许可、渠道、供应链、数据和客户转换成本。必要时使用五力，但必须落到证据和经济结果。

### 8.2 参与者分层

覆盖：直接竞品、邻近竞品、传统方案、内部自建、通用工具、人工服务、开源替代和潜在平台吸收。不得因对方未使用相同营销词就排除。

### 8.3 可比矩阵

至少比较产品任务、客户、功能、效果、价格、销售方式、商业模式、部署/安全、交付周期、单位经济、留存/增长、融资与经营状态。管理层自报用户数或收入要标记来源与独立性。

对关键竞品建立可复现测试：同一数据集、同一任务、领先通用基线、人工基线、指标、盲评、成本和误报/失败模式。架构名词和功能清单不构成护城河。

## 9. 趋势、技术与监管

- 趋势：区分已发生、正在形成和仅有叙事；说明证据、受益/受损方和时间窗口。
- 技术：分析性能、成本曲线、商品化、开源/平台吸收、替代速度和标的依赖。
- 监管：使用主管部门和正式法规为主，区分生效、发布、征求意见和地方实践；说明准入、许可、数据、内容、消费者、跨境和持续合规影响。
- 资本与退出：融资或并购只能证明资本关注，不能代替客户付费和 PMF；估值倍数及交易价格放入回报分析。

## 10. 标的映射与投资含义

把行业结论映射到标的：

- 当前收入对应哪个市场切片；
- 预测隐含多少渗透、份额、价格和客户增长；
- 核心能力是否针对价值链瓶颈，还是会被通用平台商品化；
- 毛利、销售周期、回款、资本开支和合规成本是否符合行业；
- 进入窗口、里程碑、止损条件、条款和估值应如何调整。

行业结论必须能明确支持、限制或反驳投资主张，而不是只给“前景广阔”。

## 11. 取证与来源纪律

优先使用监管/统计/协会原始数据、上市公司披露、公司官方产品与定价、学术论文、法院/专利/注册信息和可复现测试。专业数据库和报告可补充；媒体和公司自报必须标示局限。

记录检索日期、发布日期、原始链接/文件、页码或定位、定义、独立性组别和摘录限制。同一报告被多家媒体转载仍是一个独立来源。证据不足时创建具体 evidence request，并在本工作流内按 `references/shared/source-grading.md` 补证。
